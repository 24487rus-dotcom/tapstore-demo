# TapStore — интерактивное демо

[Открыть публичное демо](https://24487rus-dotcom.github.io/tapstore-demo/#/shop/demo)

Русскоязычная демонстрация конструктора витрин для магазинов с самовывозом.

## Как попробовать

1. Добавьте товар в корзину, укажите имя и оформите тестовую заявку.
2. Нажмите «Сотрудник», примите заявку, отметьте готовность и выдачу.
3. Нажмите «Владелец» и откройте «Аналитика», чтобы увидеть результат.
4. Кнопка «Сбросить демо» возвращает тестовые данные после подтверждения.

## Возможности

- Отдельные кабинеты покупателя, сотрудника и владельца.
- Несколько магазинов, настройка витрины и подсказки запуска.
- Каталог с фотографиями, скидками и наличием товаров.
- Корзина, самовывоз, статусы и автоматическое обновление заявок.
- Управление сотрудниками и разрешениями на изменение цен.
- Аналитика заявок и финансовый отчёт с ручным вводом доходов и расходов.

## Данные демонстрации

Данные сохраняются в браузере посетителя. Роли переключаются без настоящей авторизации. Все магазины, операции и заявки демонстрационные. Фотографии, добавленные посетителем, сохраняются локально в его браузере. Реальных продаж и оплаты нет.

## Публикация и запуск

GitHub Pages публикует каталог docs из ветки main. Установка зависимостей не требуется. Для локальной проверки запустите любой статический веб-сервер над docs. Пример с Node.js и установленным пакетом http-server: npx http-server docs. Откройте напечатанный адрес. Пути определяются автоматически, включая размещение в подпапке.
