# TapStore — сайт и кабинет небольшого магазина

## Начать с презентации

**[Открыть TapStore: описание проекта и возможности](https://24487rus-dotcom.github.io/tapstore-demo/)**

На главной: кому подходит сервис, витрина, заявки, склад, счета, обращения и аналитика. Кнопка «Посмотреть рабочее демо» открывает тестовый магазин. В демо ссылка «О проекте» возвращает на презентацию.

[Рабочее демо на русском](https://24487rus-dotcom.github.io/tapstore-demo/demo/?lang=ru&currency=RUB#/shop/demo) · [English demo](https://24487rus-dotcom.github.io/tapstore-demo/demo/?lang=en&currency=USD#/shop/demo)

## Доставка

В учебном магазине доставка включена по умолчанию. Для ранее сохранённых данных применяется однократное обновление настройки, без удаления товаров и заявок. После этого владелец может выключить доставку: Владелец → Витрина → Принимать запросы доставки.

Покупатель выбирает «Запрос доставки», указывает контакт, адрес и комментарий. Сотрудник видит их в заявке. Стоимость и время согласовываются вручную; курьерские службы не подключены.

## Как попробовать

1. На презентации нажмите «Посмотреть рабочее демо».
2. Добавьте товары, выберите самовывоз или запрос доставки и оформите тестовую заявку.
3. Переключитесь на сотрудника и обработайте заявку.
4. В кабинете владельца доступны каталог, склад, счета, обращения, аналитика и настройки витрины.

## Ограничения демонстрации

Данные сохраняются только в браузере посетителя. Роли переключаются без реальной авторизации. Настоящих продаж и оплаты нет. Платные запросы ИИ выключены. GitHub Pages размещает статические страницы; для настоящего распознавания и сохранения партнёрских заявок нужен сервер. Партнёрская кнопка указывает на действующую серверную площадку.

RU/EN и RUB/USD/EUR переключаются в демо. Курсы демонстрационные, базовая валюта ввода — RUB.

## Запуск

GitHub Pages публикует каталог docs из main. Презентация: docs/index.html; рабочее приложение: docs/demo/index.html. Для локального просмотра используйте статический веб-сервер. Старые ссылки с #/shop, #/manage и #/buyer автоматически перенаправляются в раздел demo.
