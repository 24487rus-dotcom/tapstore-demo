# TapStore — интерактивное демо

[Открыть демонстрацию](https://24487rus-dotcom.github.io/tapstore-demo/)

Витрина на русском: каталог, корзина, самовывоз, бонусы, роли покупателя, продавца и владельца, настройка бренда и простая аналитика.

## Как попробовать

1. Добавьте товары и создайте учебную заявку.
2. Переключитесь на продавца и проведите заявку до выдачи.
3. Проверьте бонусы у покупателя и показатели у владельца.

Данные учебного магазина сохраняются в текущем браузере. Реальных продаж, алкоголя и оплаты нет. Расписание, цены и условия — примеры.

## Партнёрские заявки

GitHub Pages размещает только демонстрацию. Кнопка партнёра предлагает переход на отдельный защищённый сайт с серверной формой. Там потребуется вход через ChatGPT и разрешённый доступ к сайту. Контакты заявителей в репозиторий не включены.

## Публикация

Settings → Pages: Deploy from a branch → main → /docs. Изменения в docs публикуются автоматически. Для локального просмотра откройте docs/index.html.
