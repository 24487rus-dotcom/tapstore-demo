# Серверный пилот TapStore

Публичное демо на GitHub хранит только тестовые данные в браузере. Серверный пилот находится по адресу https://tapstore-demo-ruslan.violetleaf7.chatgpt.site/pilot/.

## Запуск
1. Войти через ChatGPT с почтой владельца проекта (LEAD_OWNER_EMAIL).
2. Создать один магазин, указать контакты, часы и адрес.
3. Добавить товары вручную или загрузить CSV из раздела «Каталог».
4. В разделе «Витрина» включить доставку и указать стоимость, минимум, бесплатный порог и зоны через |. 0 в бесплатном пороге означает, что освобождение от оплаты по сумме выключено. Минимум и порог считаются после скидок, без доставки. Настройки принадлежат магазину, не являются общим тарифом платформы.
5. Опубликовать витрину, скопировать ссылку. Владелец добавляет почту ChatGPT сотрудника и права изменения цен. Сотрудник входит с этой почтой.

## Проверки и ограничения
- Данные пилота общие: D1, фотографии R2; авторизация проверяется сервером. Пилот ограничен одним магазином владельца проекта. Это ещё не открытая регистрация магазинов для всех желающих.
- Изменения версионируются, конфликтующие заявки повторяются с проверкой остатка. Списание доставки при передаче курьеру, повторного списания при завершении нет.
- CSV: UTF-8, до 500 новых позиций; сначала проверка и подтверждение. Нет массового обновления, фото и количественных остатков через CSV.
- Для работы нужен интернет. При потере связи нет ложного сообщения об успешном сохранении. Локальная очередь отправки не реализована.
- Автоматические тесты покрывают доставку, конкурентные заявки, права, отключение сотрудника и импорт. Проверка мобильной ширины в браузере не заменяет тест на настоящих Android/iPhone. Камера и установка на физическом телефоне ещё не подтверждены.
- Распознавание ИИ выключено. Платные запросы не выполнялись.
- Не подключены онлайн-оплата и курьерские службы. Это пилот, не готовая кассовая/бухгалтерская система. До рабочих персональных данных нужны эксплуатационные процедуры резервирования и восстановления и проверка требований магазина.
- Состояние хранится единым версионированным документом до 1.5 МБ. Подходит для небольшого пилота; для роста нужны отдельные таблицы, пагинация и политика хранения.
